RegexKit 개인정보처리방침

RegexKit은 사용자의 개인정보를 수집, 저장, 판매하거나 외부 서버로 전송하지 않습니다.

RegexKit은 사용자가 정규식을 테스트하고, 정규식 패턴을 관리하며, 다양한 프로그래밍 언어용 정규식 코드 스니펫을 생성할 수 있도록 돕는 개발자 도구입니다.

1. 데이터 처리

RegexKit의 정규식 테스트, 패턴 매칭, 매치 결과 하이라이트, 캡처 그룹 분석, 코드 스니펫 생성 기능은 모두 사용자의 브라우저 내부에서 로컬로 처리됩니다.

RegexKit은 사용자가 입력한 정규식 패턴, 테스트 텍스트, 웹페이지에서 선택한 텍스트, 생성된 코드 스니펫을 외부 서버로 전송하지 않습니다.

2. 로컬 저장 데이터

RegexKit은 사용자 편의를 위해 Chrome 로컬 저장소를 사용할 수 있습니다.

저장될 수 있는 정보는 다음과 같습니다.

  • 사용자가 직접 추가한 사용자 정의 정규식 패턴
  • 테마 설정
  • 마지막으로 선택한 프로그래밍 언어
  • 임시 에디터 설정

이 데이터는 chrome.storage.local을 통해 사용자의 브라우저 내부에만 저장됩니다.

RegexKit은 방문 기록, 개인정보, 비밀번호, 결제 정보, 웹페이지 전체 내용 등을 저장하지 않습니다.

3. 웹페이지에서 선택한 텍스트

RegexKit은 사용자가 웹페이지에서 텍스트를 선택한 뒤, 브라우저 우클릭 메뉴를 통해 해당 텍스트를 RegexKit 테스터로 전달하는 기능을 제공할 수 있습니다.

이 기능은 사용자가 명시적으로 텍스트를 선택하고 RegexKit 메뉴를 실행한 경우에만 동작합니다.

선택된 텍스트는 사용자의 브라우저 내부에서만 처리되며, 외부 서버로 전송되지 않습니다.

4. 권한 사용

RegexKit은 핵심 기능 제공을 위해 필요한 브라우저 권한만 요청합니다.

activeTab 권한

activeTab 권한은 사용자가 현재 활성 탭에서 확장프로그램 기능을 명시적으로 실행했을 때만 사용됩니다.

이 권한은 사용자가 선택한 웹페이지 텍스트를 RegexKit에서 테스트할 수 있도록 처리하는 데 필요합니다.

scripting 권한

scripting 권한은 사용자가 관련 기능을 실행했을 때 현재 웹페이지에서 선택한 텍스트를 읽기 위해 사용됩니다.

스크립트는 사용자의 명시적인 동작 없이 자동으로 주입되거나 실행되지 않습니다.

storage 권한

storage 권한은 사용자가 직접 추가한 정규식 패턴과 로컬 UI 설정을 저장하기 위해 사용됩니다.

저장된 데이터는 사용자의 브라우저 내부에만 보관됩니다.

contextMenus 권한

contextMenus 권한은 사용자가 웹페이지에서 선택한 텍스트를 RegexKit으로 빠르게 테스트할 수 있도록 브라우저 우클릭 메뉴를 추가하기 위해 사용됩니다.

5. 제3자 서비스

RegexKit은 제3자 분석 도구, 추적 스크립트, 광고 네트워크 또는 외부 서버를 사용하여 사용자 데이터를 처리하지 않습니다.

RegexKit은 사용자 데이터를 제3자에게 전송하지 않습니다.

6. 원격 코드

RegexKit은 원격 JavaScript 코드를 실행하지 않습니다.

확장프로그램의 모든 핵심 로직은 확장프로그램 패키지 내부에 포함되어 있습니다.

7. 데이터 공유

RegexKit은 사용자 데이터를 판매, 공유 또는 제3자에게 이전하지 않습니다.
